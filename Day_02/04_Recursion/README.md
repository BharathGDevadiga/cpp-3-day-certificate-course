# Recursion

Programs demonstrating recursive functions in C++ — functions that call themselves to solve problems by breaking them into smaller subproblems.

## Concepts Covered

- Base case and recursive case
- Printing in increasing/decreasing order using recursion
- Factorial and power calculation using recursion
- The classic Tower of Hanoi problem
- Understanding the call stack through print order

## Programs

| File | Description |
| --- | --- |
| [print_increasing.cpp](print_increasing.cpp) | Prints numbers 1 to N using recursion (prints after recursive call). |
| [print_decreasing.cpp](print_decreasing.cpp) | Prints numbers N to 1 using recursion (prints before recursive call). |
| [print_increasing_decreasing.cpp](print_increasing_decreasing.cpp) | Prints N to 1 then 1 to N in a single recursive function. |
| [print_name_n_times.cpp](print_name_n_times.cpp) | Prints a user's name N times using recursion. |
| [reach_home.cpp](reach_home.cpp) | Simulates reaching a destination step by step using recursion. |
| [factorial_recursion.cpp](factorial_recursion.cpp) | Calculates factorial of a number (5! = 120) using recursion. |
| [power_recursion.cpp](power_recursion.cpp) | Calculates power (2^5 = 32) using recursion. |
| [tower_of_hanoi.cpp](tower_of_hanoi.cpp) | Solves the classic Tower of Hanoi problem for 3 disks. |
