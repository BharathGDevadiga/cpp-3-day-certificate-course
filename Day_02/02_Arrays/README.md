# Array Operations

Programs demonstrating array creation, traversal, and common operations like finding the largest element, computing sums, and squaring values.

## Concepts Covered

- Declaring and initializing arrays
- Reading array elements from user input
- Iterating through arrays with `for` loops
- Finding max element, computing sum, and transforming elements
- Counting even and odd numbers in an array

## Programs

| File | Description |
| --- | --- |
| [print_array_elements.cpp](print_array_elements.cpp) | Prints all elements of a predefined array. |
| [read_print_array.cpp](read_print_array.cpp) | Reads array values from the user and prints them. |
| [sum_array_elements.cpp](sum_array_elements.cpp) | Calculates the sum of all elements in an array. |
| [square_array_elements.cpp](square_array_elements.cpp) | Prints the square of every array element. |
| [largest_array_element.cpp](largest_array_element.cpp) | Finds the largest element in a user-input array. |
| [count_even_odd.cpp](count_even_odd.cpp) | Counts the number of even and odd values in an array. |
