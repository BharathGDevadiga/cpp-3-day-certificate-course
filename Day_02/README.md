# Day 02 - C++ Practice

This folder contains beginner-friendly C++ programs covering functions, arrays, strings, and recursion. The programs have been grouped into topics for easier navigation.

## Topics

1. **[Functions](01_Functions/)**
   - Function declaration and calling
   - Returning values
2. **[Arrays](02_Arrays/)**
   - Creating and traversing arrays
   - Finding largest elements and calculating sums
3. **[Strings](03_Strings/)**
   - String manipulation and character counting
   - Reversing and formatting cases
4. **[Recursion](04_Recursion/)**
   - Solving problems via recursive functions
   - Classic problems like Tower of Hanoi

## Exploring the Code

Each subfolder contains the C++ source files for that topic along with a local `README.md` explaining the concepts and listing the programs. The expected output for each program is also included as a comment block at the bottom of the respective `.cpp` file!

## How to Compile and Run

Navigate into any topic folder and compile a program with `g++`:

```powershell
cd 01_Functions
g++ area_of_circle.cpp -o area_of_circle
.\area_of_circle
```

## Requirements

- A C++ compiler such as `g++`
- C++11 or later
