# Functions & Function Calls

Programs demonstrating how to define and call functions in C++, including passing arguments, returning values, and calling one function from another.

## Concepts Covered

- Function declaration and definition
- Passing parameters and returning values
- Calling a function from within another function
- Using functions for modular code (area calculation, even/odd check)

## Programs

| File | Description |
| --- | --- |
| [function_call_demo.cpp](function_call_demo.cpp) | Demonstrates calling one function from another (`city()` calls `bangalore()`). |
| [sum_using_function.cpp](sum_using_function.cpp) | Adds two user-input numbers using a function. |
| [area_of_circle.cpp](area_of_circle.cpp) | Calculates the area of a circle using a separate `area()` function. |
| [evenOrodd.cpp](evenOrodd.cpp) | Checks whether a number is even or odd using a boolean function. |
