# Comparison & Bitwise Operators

Programs demonstrating different types of operators in C++ including relational/comparison operators and bitwise shift operators.

## Concepts Covered

- Comparison operators: `>`, `<`, `>=`, `<=`, `==`, `!=`
- `boolalpha` for readable boolean output
- Bitwise left shift (`<<`) and right shift (`>>`)
- Binary number representation

## Programs

| File | Description |
| --- | --- |
| [comparison_operators.cpp](comparison_operators.cpp) | Demonstrates all comparison operators using two integers. |
| [bitwise_shift_operators.cpp](bitwise_shift_operators.cpp) | Demonstrates left-shift and right-shift bitwise operators on binary values. |
