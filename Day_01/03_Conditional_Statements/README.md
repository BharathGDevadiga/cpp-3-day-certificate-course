# Conditional Statements

Programs demonstrating decision-making in C++ using `if`, `else if`, `else`, nested conditions, and `switch` statements.

## Concepts Covered

- `if-else` for checking positive, negative, or zero
- Nested `if-else` and the dangling-else problem
- `switch-case` for menu-driven selection
- Absolute value calculation

## Programs

| File | Description |
| --- | --- |
| [number_sign_and_absolute_value.cpp](number_sign_and_absolute_value.cpp) | Checks if a number is negative, positive, or zero and prints its absolute value. |
| [nested_if_else.cpp](nested_if_else.cpp) | Demonstrates nested `if-else` and the dangling-else behavior. |
| [switch_case_demo.cpp](switch_case_demo.cpp) | Selects an output using a `switch` statement. |
| [calculate_shape_area.cpp](calculate_shape_area.cpp) | Calculates the area of a circle, rectangle, or triangle using `switch`. |
