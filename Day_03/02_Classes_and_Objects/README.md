# Classes, Constructors & Encapsulation

Programs demonstrating the fundamentals of Object-Oriented Programming in C++ — creating classes, using constructors for initialization, and encapsulation with getters/setters.

## Concepts Covered

- Defining classes with member variables and methods
- Creating objects and accessing members
- Default constructors for automatic initialization
- Parameterized constructors with default values
- Encapsulation using `private` members with `public` getters/setters
- `const` member functions for read-only access

## Programs

| File | Description |
| --- | --- |
| [class_and_object.cpp](class_and_object.cpp) | Creates a `student` class with `name` and `age`, and displays details. |
| [rectangle_area.cpp](rectangle_area.cpp) | Calculates the area of a rectangle using a class with a method. |
| [default_constructor.cpp](default_constructor.cpp) | Demonstrates a constructor that runs automatically when an object is created. |
| [default_constructor_with_member_values.cpp](default_constructor_with_member_values.cpp) | Constructor that initializes member variables with default values. |
| [student_default_constructor.cpp](student_default_constructor.cpp) | Student class with a default constructor and display method. |
| [const_member_function_encapsulation.cpp](const_member_function_encapsulation.cpp) | Demonstrates encapsulation with private data, setter, and `const` getter. |
