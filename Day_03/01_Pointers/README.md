# Pointer Basics & Arithmetic

Programs demonstrating pointers in C++ — variables that store memory addresses. Covers declaration, dereferencing, pointer arithmetic, pointer-to-pointer, and passing pointers to functions.

## Concepts Covered

- Declaring pointers with `*` and getting addresses with `&`
- Dereferencing pointers to access/modify values
- Pointer arithmetic (incrementing to traverse arrays)
- Size of pointers vs size of data types
- Pointer-to-pointer (double pointer `**`)
- Passing pointers to functions (pass by reference)
- Swapping values using pointers
