# Inheritance, Polymorphism & Abstraction

Programs demonstrating advanced Object-Oriented Programming concepts in C++ — inheriting properties, method overriding, function overloading, and abstract classes.

## Concepts Covered

- Inheritance (creating a child class from a parent class)
- Function overloading (compile-time polymorphism)
- Method overriding and virtual functions (runtime polymorphism)
- Abstract classes and pure virtual functions (`= 0`)

## Programs

| File | Description |
| --- | --- |
| [inheritance_animal_dog.cpp](inheritance_animal_dog.cpp) | Demonstrates single inheritance where `Dog` inherits from `Animal`. |
| [function_overloading.cpp](function_overloading.cpp) | Compile-time polymorphism using multiple `add` functions with different parameters. |
| [runtime_polymorphism.cpp](runtime_polymorphism.cpp) | Runtime polymorphism using virtual functions and a base class pointer. |
| [abstract_class_pure_virtual_function.cpp](abstract_class_pure_virtual_function.cpp) | Demonstrates an abstract class (`vehicle`) with a pure virtual function. |
