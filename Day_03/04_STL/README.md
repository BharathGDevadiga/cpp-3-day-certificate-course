# Standard Template Library (STL)

Programs demonstrating the use of C++ Standard Template Library containers.

## Concepts Covered

- `vector` for dynamic arrays
- `set` for collections of unique elements, sorted automatically
- Range-based for loops

## Programs

| File | Description |
| --- | --- |
| [vector_example.cpp](vector_example.cpp) | Demonstrates adding elements to a `vector` using `push_back()` and iterating through them. |
| [set_example.cpp](set_example.cpp) | Demonstrates creating a `set`, which automatically removes duplicates and sorts elements. |
